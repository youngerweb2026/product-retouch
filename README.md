# 产品精修

作者：**不二何** · Skill 标识：`product-retouch`

上传一张产品照片，直接制作**新品状态的商业电商展示图**。清除磨损、划痕、污渍、水垢和老化，同时保留商品的款式、结构、材质、原色及标识。默认使用 Codex 内置 ImageGen，提示词为中文。

默认交付两类、共 **4 张独立的 1:1 正方形白底图**，每张是单独文件，主体完整、居中、留白均衡：

| 文件 | 内容 | 视角 |
| --- | --- | --- |
| `01_原视角精修.png` | 原视角新品精修 | 保留原拍摄角度与商品摆放方向，整理为正方形主图 |
| `02_正视图.png` | 正视主图 | 对准产品主要正面，基本水平拍摄 |
| `03_30度侧视图.png` | 30°侧视主图 | 相对正面水平转约30° |
| `04_45度微俯视图.png` | 45°微俯视主图 | 水平转约45°，再轻微下俯约10°–20° |

45°微俯视中的45°指水平转角。四张统一商品、材质、色彩、灯光与精修尺度；不会拼成四格图，也不会只输出提示词。

完整执行规则见 [SKILL.md](product-retouch/SKILL.md)，材质处理与视角规范见 [精修参考](product-retouch/references/retouch-guide.md)。

## 终端一行安装

已安装 Node.js 和 npm 时：

```bash
npx --yes skills add youngerweb2026/product-retouch --skill product-retouch --agent codex --global --yes
```

此命令使用第三方 `skills` CLI，安装到 Codex 的个人 Skills 范围。已有同名且包含本地修改的 Skill 时，优先使用上面的 Codex 安装指令，先比较版本。

## 使用方法

1. 安装并让当前对话加载该 Skill。
2. 选择“产品精修”或发送 `$product-retouch`。
3. 上传一张产品图。技能已处于当前上下文时，只上传图片也会直接执行。

也可以随图片发送：

```text
使用「产品精修」，把这张产品图修成新品状态，输出完整四张正方形白底电商主图。
```

默认不再要求用户写提示词、挑风格或逐张确认。先完成并检查原视角精修，再使用原图保持商品身份、用合格精修图统一材质和光色，继续完成三个新视角。

## 精修标准

- **新品外观**：清除使用造成的划痕、擦伤、磕碰、掉漆、锈斑、水垢、污渍、塑料泛白与老化；旧品输入也默认修成同款新品状态。
- **商品保真**：保留款式、比例、原色、材质工艺、部件数量、接口按键、装配关系、Logo和文字。制造纹理、功能接缝及天然纹理仍保留。
- **商业布光**：按金属、塑料、玻璃、织物等实际材质分别处理反射和微表面；高光连续、暗部有细节、边缘干净，白底配轻柔接触阴影。
- **画面统一**：四张均为正方形白底，主体最长边约占75%–85%，完整展示，尺度与光色一致，不添加文案、道具或新卖点。

新品修复改变商品的表面状态，款式和功能设计保持。只有明确要求二手实物展示或保留磨损时，才保留对应使用痕迹。

## 局部修改与样张

只生成一张样图时：

```text
先只做原视角的新品精修样图，其他视角暂时不生成。
```

修改指定图片时：

```text
只修改03的30度侧视图，保留这次的新品效果与颜色，把主体稍微缩小，其他三张不变。
```

当次明确要求的张数、比例、背景或修改范围优先。只要分析、只要提示词、讨论或调整 Skill 时，不自动生成图片；同时要求重修或样图时，完成指定图片。

## 交付与能力范围

默认保存四张独立图片与实际使用的中文提示词，已有原图和确认版本保留。验收会查看实际成图，检查新品表面、商品结构、文字、边缘、阴影、画幅与各视角差异，按需修正有问题的图片。

本 Skill 需要能实际查看图片并调用 Codex 内置 ImageGen 的环境。安装本身不要求先配置图片 API 密钥；其他 Agent 能否自动出图，取决于其工具能力。不会自行切换到外部生图平台。

单张照片的新视角是依据可见形体进行的保守推演，角度为摄影构图目标。未展示的复杂背面、隐藏接口及内部结构不当作已核实事实；信息确实不足时会说明具体缺少的角度，不编造零件来凑图。
