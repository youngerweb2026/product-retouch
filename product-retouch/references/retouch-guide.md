# 精修判断与材质处理

供实际看图后按需选用。默认目标是商品新品状态的商业电商精修；保真指保留款式、结构、材质、原色和标识，不要求保留旧品磨损。新视角基于可见形体保守推演，不新增没有依据的复杂结构。

## 精修边界

处理优先级：商品身份与结构 → Logo、文字、图案与原色 → 几何比例与装配关系 → 材质与工艺 → 背景灯光 → 适度清晰度。

- 默认修复：灰尘、指纹、污渍、水垢、氧化锈斑、划痕、擦伤、磕碰凹痕、掉漆、表面老化裂纹和塑料泛白，恢复同款新品应有的干净、完好表面；清理背景杂物、支架与杂乱反射。移除遮挡后真正缺失或无法确认的功能结构不凭空设计。
- 应保留：加工纹、焊点、模线、接缝、天然孔隙、石纹、木纹、皮纹、功能褶皱与有设计作用的不对称结构。
- 不等待用户额外说“翻新”：旧品输入也默认去除损伤和旧化。仅用户明确要二手实物原貌、保留使用痕迹时才保留磨损。识别材质制造纹理与随机损伤的区别，不能为了新品感把材质全部抹平。
- 原图切掉或遮住的关键结构，不通过“完整展示”指令强制补全。低清、模糊只做有限改善，不能声称恢复了原图没有的信息。

## 透视、几何与镜头观感

只凭可见线条和比例判断“自然、轻度畸变、明显畸变或无法可靠判断”。没有 EXIF 就不认定原图的真实焦距。

- 近大远小、斜视圆面变成椭圆、平行边在透视中汇聚，本身都可能正常。结合轴线、制造结构、边缘拉伸及对称关系判断，不强行把所有圆面变圆或把所有边拉平。
- 长方体：保持自然三维关系与印刷平面，不能挤压整张图造成文字变形。
- 圆柱体：中心轴、口径与当前观察角度相符；瓶口椭圆不等于畸变。
- 对称件：中轴可作轻度校正依据，但不能抹掉真实偏置按键、孔位或把手。
- 软体：整理整体版型，保留自然柔软、曲线和垂坠，不修成硬壳。
- 大型器具：校正明显倾斜的垂直线和接地关系；不增加结构和尺寸线。

需要纠正手机近摄的明显拉伸时，可用以下“镜头观感”描述修复目标；它们不是原图焦距，也不意味着要换成新视角：

| 商品 | 可参考的镜头观感 |
| --- | --- |
| 珠宝、腕表、精密小件 | 90–120mm 微距，自然比例 |
| 数码、瓶罐、餐具、鞋包等中小商品 | 70–105mm |
| 服装、较大软装 | 70–100mm |
| 家具、家电 | 45–70mm，垂直线自然 |
| 工业设备 | 50–85mm，避免边缘拉伸 |

## 材质与布光

混合材质分别处理，不能给整件商品套同一种光泽。只使用照片可支持的工艺描述，不从观感推断纯度、等级或真伪。整齐、方向一致的拉丝是工艺，应保留；随机交叉划痕、锈蚀、龟裂和斑驳是使用损伤，默认清除。塑料恢复均匀的新品微表面，不保留老化起灰、掉色与伤痕；制造模线和装配缝保持原样。

| 材质／类目 | 精修重点 | 应避免 |
| --- | --- | --- |
| 镜面金属、镀铬、抛光五金 | 大柔光板形成连续克制的亮暗反射带，保留倒角与边缘厚度 | 脏环境映射、整面死白死黑、塑料化 |
| 拉丝、喷砂、阳极氧化金属 | 保留原方向拉丝或均匀微粗糙度，反射带宽而柔 | 用噪点代替纹理、拉丝跨接缝、磨成灰塑料 |
| 贵金属、宝石、腕表 | 保留金属原色、可见切面、镶爪数量、表冠与刻度；清理灰尘 | 自发光宝石、夸大火彩、改变宝石大小与数量、宣称纯度 |
| 玻璃、水晶、透明亚克力、液体 | 保留厚度、透射、折射、液面、液体原色；用边缘亮线分离轮廓 | 玻璃乳化、双重边缘、瓶内残留旧背景、错误液面 |
| 塑料、树脂 | 区分亮面、磨砂、半透明与注塑纹，保留微表面和真实透明度 | 油膜、蜡感、陶瓷化、抹掉模线 |
| 硅胶、橡胶、软触涂层 | 低反射、细微软触纹理、自然弹性形态 | 硬壳感、湿油感、橡皮泥感 |
| 陶瓷、釉面 | 保留釉层、坯体与边缘厚度，柔和高光揭示曲面 | 塑料质感、过曝吞边 |
| 石材、水泥 | 保留天然纹理、颗粒、细孔与不规则性 | 重复贴图、过锐、磨平孔隙 |
| 木、竹、藤编 | 纹理沿原结构延伸，保留拼接、封边、孔隙与编织交叠 | 跨接缝木纹、重复纹理、过黄过红 |
| 皮革、鞋包 | 保留皮纹、缝线、边油、五金及必要折弯 | 磨成塑料、缝线错位、改变包体或鞋楦 |
| 织物、服装、家纺 | 保留织法、纤维、绒毛、结构缝线和垂坠；去无关线头 | 假毛发、摩尔纹、布料硬片化、凭空生成人体 |
| 数码、家电 | 接口、开孔、按键、镜头、屏幕、装配缝准确，反射克制 | 重画 UI、换屏内容、增减接口与功能 |
| 香水、化妆品、瓶罐包装 | 分别处理玻璃、塑料、金属；保留泵头、瓶盖、液面、烫印与标签 | 标签改写、容量变化、瓶口或盖子变款 |
| 食品、饮料、生鲜 | 保留真实品种、形状、份量、配料及包装，适度还原对应质地 | 新增水珠、蒸汽、气泡、配料或切面，过度油亮与荧光色 |
| 家具、灯具、卫浴、工具、工业件 | 组合材质分开处理，接地与连接关系可信 | 漂浮、爆炸图、擅自开灯或改变开合状态 |
| 医疗器具、实验用品、纸盒、印刷品 | 保留刻度、印刷、折线、原有认证图形与文字 | 新增功效、认证、参数、品牌或安全标志 |

未列出类目按“材质＋制造工艺＋几何结构＋功能部件”拆解后处理，不套用无关行业的质感。

## 背景与光色

- 默认四张全部采用不透明纯白无缝背景，轻柔接触阴影，商品不漂浮；输入图原有透明背景也不改变此默认。原图明显是悬挂或悬空拍摄时保留其真实支撑关系，不强加不相符的落地阴影。
- 白色、透明、浅色高反射商品使用轮廓光、柔灰反射带和边缘亮暗控制分离主体；背景仍保持白色，不自动改成灰底、黑底或透明底。
- 用户另行明确要求原背景则只清理、校色与匹配光线；明确要求透明底则保留真实透明通道。这些是当次覆盖，不改变默认四张白底图。
- 柔和主光、低强度补光，必要时加克制轮廓光。材质高光不过曝，暗部有细节，色温中性。
- 白平衡校正以可见中性参照为依据，证据不足时克制处理，不凭想象换成“标准品牌色”。
- 透明容器更换背景时，同时处理容器透射与折射中的旧环境残留，避免边缘抠图而内部仍是原背景。
- 不自动添加生活场景、彩色几何体、镜面地面、浓烟、光效或装饰物。

## 印刷、文字与局部检查

- 原有 Logo、文字、标签、条码、认证图形与刻度保留原位置、内容、方向和颜色；不翻译、不改写、不重排，不新增不确定的品牌型号。
- 小字无法辨认时优先保留原印刷区域，不让模型根据商品类别猜写。不能把“小字看上去差不多”当成字符核验通过。
- 产品轮廓和印刷区域是重点对照区域；透明瓶体、反射金属与细链检查重影、断裂、粘连、穿插和不合理反射。
- 画面清晰度用自然锐度、真实微纹理、适度降噪来描述，不用“8K、极致锐化”替代实际要求。

## 四图视角与一致性

默认是一张原视角精修图，以及三张新视角主图，合计4个独立文件，全部1:1白底。禁止沿用资料中的“大主视图＋三个小辅助视图”拼版，禁止以裁切细节替代指定视角。

### 正面和角度定义

- 根据产品主要展示面、使用方向、品牌面和结构确定正面；不能把原照片的任意斜侧面称为正视图。明显没有固定正面的旋转对称产品，以主要标签或识别面建立统一正面基准。
- **01原视角精修**：保留输入照片的观察方向与俯仰角，清除使用损伤并修成新品状态，同时整理拍摄问题；构图调整为正方形居中主图，不继续保留原图多余的单侧空白或杂物。
- **02正视图**：相机对准正面中心，基本水平，正面居中、不带明显水平侧转；避免强俯拍、仰拍和广角变形。
- **03的30°**是相对上述正面基准的水平转角，展示正面与原图证据较多的一侧，不是纯90°侧面，也不是把整张图片在平面内旋转30°。
- **04的45°**是水平转角约45°；“微俯视”指相机略高，额外下俯约10°–20°，让顶部适度可见，不能误做成45°向下俯拍或垂直顶视。用户另行指定俯角时按其要求。
- 03与04展示同一侧，不做左右镜像来凑角度；保留非对称把手、壶嘴、拨杆、接口、按键的位置关系。角度是生成构图目标，不是经标定的工程测量值。

### 统一商品与摄影条件

01先完成并检查新品修复效果。02–04每次都参考原始产品照片确定身份，并参考合格01统一新品表面、原色、材质、灯光和精修尺度，不复制原图的磨损污垢，不用上一张新视角代替原始依据。

各图统一主光方向、色温与接地阴影风格；不要求高光纹路在不同视角像贴图一样完全相同，反射应随新观察角度合理变化。主体完整居中，最长边约占75%–85%，边距整齐，视觉尺度接近。不得通过压扁或拉长商品来统一占比。

各视图Logo、印刷和标签应随承载表面合理透视、遮挡，原本看不到的面不强加Logo。保持原内容、字体关系和原色；不能把文字贴在所有视图的相同画面坐标，不能把被遮住的部件搬到前面来保证“都可见”。

### 单图推演的限度

用户只上传一张图也直接推进四图，允许基于已知轮廓、连续曲面和可见装配做保守的视角转换。未知平整表面保持与可见材质一致，不新增背面文字、隐藏接口、孔位、水位窗、显示屏或其他复杂功能部件；不主动生成背面、底面、内部或拆解图。

若原图关键区域被裁切、严重遮挡或不足以判断复杂零件的真实关系，不能为了凑四图随意设计。先交付能够完成的图片，指出哪张需要补充哪个角度；不能暗中重复角度、换成细节图或把未知结构表述为已经核实。普通画面不要求用户先提供三张标准视图，也不增加常规确认环节。
